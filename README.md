# Pokémon Statistics Dashboard.

This project features a ** Workbook** with different visualizations for analyzing Pokémon statistics, including Attack, Defense, Speed, HP, and Total.

## 🚀 Included Visualizations

* **Scatter Plot:** relationship between Attack and Defense, with color representing Total and size representing Speed.
* **Grouped Bubble Chart:** comparison of attributes using bubbles with different sizes and colors.
* **Attribute Heatmap:** color-coded table to identify strengths and weaknesses.

## ⚙️ Technical Features

* Dataset containing multiple Pokémon attributes.
* Use of `Measure Names` and `Measure Values` to display multiple metrics.
* Application of diverging color palettes to highlight extreme values.
* Interactive visualizations built in Tableau.
